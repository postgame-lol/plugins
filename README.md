# postgame.lol plugins

[postgame.lol](https://postgame.lol) reviews your League of Legends games from their replays: the moments that
cost you, what to do instead, and the mistakes you keep making across games. These plugins bring it to your AI
assistant.

## postgame

Connects your assistant to your postgame.lol account (you sign in and approve it once), with skills to review a
game and to coach you across games.

- **Claude Code:** `/plugin install postgame --marketplace postgame-lol/plugins`
- **Codex / ChatGPT:** add this repo as a plugin marketplace, then install `postgame`
- **Any MCP client:** add the remote MCP server `https://mcp.postgame.lol/mcp`

Then ask: "Review my last League game", "What mistakes do I keep making?", "What should I work on to climb?"
